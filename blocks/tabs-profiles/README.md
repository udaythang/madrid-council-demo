# tabs-profiles

Custom **tabs** block. Purpose: tabbed panel where one tab shows circular profile photos with links and another a multi-column link list.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: tab label; cell 2: tab content (images with links become a profile row; a list becomes a 1-2-4 column link grid).

## Supported variations

No variations.
