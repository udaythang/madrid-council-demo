# cards-news-mosaic

Custom **cards** block. Purpose: news mosaic where the first story is featured large and the others stack beside it.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1: image; cell 2: linked title. The first row is the featured card.
