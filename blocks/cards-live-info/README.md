# cards-live-info

Custom **cards** block. Purpose: live city information boxes (weather, air quality, traffic, mobility) with a status slot.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: cell 1 (optional): icon image; cell 2: title link and description; cell 3 (optional): status value.
